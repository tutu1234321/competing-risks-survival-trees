# 5.25-KM

## 📝 Описание обновлений / 版本更新说明

В исправленной версии полностью исключён CIF, сохранены только кривые KM для каждого риска, исправлены обработка данных и расчёт метрик, добавлены многокритериальные разбиения, параллельный Bootstrap и визуализация. На заново сгенерированных синтетических данных выполнено 168 проверочных комбинаций: ансамбль обычно повышает IAUCCR, но не всегда улучшает IBSCR. Основные эксперименты на больших выборках и реальных данных FreddieMac пока не выполнены.

*(在修订版中完全排除了 CIF，仅保留每个风险的 KM 曲线，修复了数据处理和指标计算，增加了多准则划分、并行 Bootstrap 和可视化。在重新生成的合成数据上完成了 168 种测试组合：集成通常能提高 IAUCCR，但并不总能改善 IBSCR。目前尚未在大型样本和真实 FreddieMac 数据上执行主要实验。)*

## 📂 Описание файлов / 文件结构说明

*   **`km_coursework.py`** (~416 строк): Модели деревьев, метрики, множественные критерии, ансамбли, циклы экспериментов и построение графиков.
    *(树模型、指标、多准则、集成、实验循环和绘图)*

*   **`histogram_core.py`** (~218 строк): Вычисление гистограмм и лог-рангового критерия (log-rank).
    *(直方图和 log-rank 计算)*

*   **`data_gen_hazardous.py`** (~500 строк): Генератор синтетических данных.
    *(合成数据生成器)*

*   **`verify_models.py`** (~69 строк): Проверка числовых значений и функциональности.
    *(数值及功能检查)*
